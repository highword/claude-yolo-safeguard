    `analyzeCommand(command: string, customRules?: Rule[]): AnalysisResult`:

    1. **Quick Reject:** Call `quickReject(command)`. If returns true → return `{ matches: [], segmentCount: 0, maxDepth: 0 }` immediately.

    2. **Platform detection (per D-46):** Simple heuristic — if command starts with PowerShell indicators (starts with any of: `Remove-Item`, `Get-`, `Set-`, `New-`, `Invoke-`, contains `|` followed by PowerShell cmdlet patterns, or contains `-Recurse`, `-Force` with PascalCase), use regex-only fallback (skip shell-quote, run COMPILED_SHELL_RULES directly against raw string). Otherwise proceed with POSIX pipeline.

    3. **Compile custom rules if provided:** Merge COMPILED_SHELL_RULES with `compileRules(customRules)`.

    4. **Recursive analysis via stack (not recursion):**
       ```typescript
       const stack: AnalysisFrame[] = [{ command, depth: 0, source: "root" }];
       const allMatches: RuleMatch[] = [];
       let maxDepth = 0;
       let segmentCount = 0;

       while (stack.length > 0) {
         const frame = stack.pop()!;
         if (frame.depth >= MAX_DEPTH) continue; // Fail-open at depth limit
         maxDepth = Math.max(maxDepth, frame.depth);

         const tokens = parseCommand(frame.command);
         const segments = splitSegments(tokens);
         segmentCount += segments.length;

         for (const segment of segments) {
           // Extract nested commands and push to stack
           const stringTokens = segment.tokens.filter(t => typeof t === "string") as string[];
           const nested = extractNestedCommands(segment.tokens);
           const subshells = extractSubshells(segment.tokens);

           for (const n of [...nested, ...subshells]) {
             stack.push({ command: n.command, depth: frame.depth + 1, source: n.source });
           }

           // Determine if this segment IS a shell wrapper (for token position suppression bypass)
           const isShellWrapperArg = frame.source === "interpreter";

           // Build token spans and run matcher
           const spans = buildTokenSpans(segment.tokens);
           const matches = matchRules(segment.original, spans, allCompiledRules, isShellWrapperArg);
           allMatches.push(...matches);
         }
       }
       ```

    5. **Deduplicate matches:** If same rule matched at same index (from recursive re-analysis), keep only unique matches (dedupe by rule.id + index).

    6. **Return:** `{ matches: allMatches, segmentCount, maxDepth }`

    **Special handling for interpreter frames (per D-27):**
    When a frame has `source: "interpreter"`, DON'T parse with shell-quote (it's not shell syntax). Instead, run regex rules directly on the command string with a synthetic single-segment/span. Set `isShellWrapperArg = true` to bypass token position suppression.
