Per D-10 through D-14:

1. **src/config/defaults.ts** — Create default configuration factory:
```typescript
import type { Config } from "../types/config";
import { DEFAULT_SEVERITY_ACTIONS } from "../types/severity";

export function getDefaults(): Config {
  return {
    severityActions: { ...DEFAULT_SEVERITY_ACTIONS },
    customRules: [],
    allowList: [],
    logging: {
      enabled: true,
      path: "~/.local/share/yolo-safeguard/audit.jsonl",
      maxSizeMb: 10,
    },
  };
}
```

2. **src/config/loader.ts** — Create the 3-layer merge logic:

Define ACTION_RANK constant: `{ off: 0, log: 1, warn: 2, block: 3 }` — higher rank = stricter.

`isEscalation(current: Action, proposed: Action): boolean` — returns true if proposed rank > current rank.

`mergeConfigs(base: Config, user: Partial<Config> | null, project: Partial<Config> | null): Config`:
- Step 1: Apply user-level overrides to base (unrestricted — user can change anything)
- Step 2: Apply project-level with restrictions:
  - severityActions: only allow if isEscalation(merged[sev], project[sev]) AND sev !== "CRITICAL"
  - customRules: concat additively (project.customRules appended to merged)
  - allowList: concat additively (project.allowList appended to merged)
  - logging: project cannot change logging config

`readJsonFile(path: string): object | null` — reads and parses JSON, returns null if file missing or invalid.

`loadConfig(cwd: string): Config`:
- Call getDefaults()
- Read user config from `~/.config/yolo-safeguard/config.json` (use `os.homedir()` + path.join)
- Read project config from `path.join(cwd, ".safeguard.json")`
- Return mergeConfigs(defaults, userConfig, projectConfig)

IMPORTANT: Use `node:fs` readFileSync (synchronous) and `node:path` join. The hook must be synchronous for <50ms latency. Use `node:os` homedir() for cross-platform home directory.

3. **src/config/index.ts** — Barrel export:
```typescript
export { getDefaults } from "./defaults";
export { loadConfig, mergeConfigs } from "./loader";
```
